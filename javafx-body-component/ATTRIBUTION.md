The supplied project merged and simplified source STL parts, oriented the body,
converted units to centimetres, and quantized geometry into `body.bin` with
metadata in `body.json`. Those two derived assets are retained unchanged here;
the Java loader changes coordinate conventions in memory for JavaFX.
Retain attribution and the applicable share-alike terms when redistributing the
model or adaptations. No broader license for the uploaded project's code was
present in the archive; this extraction does not assign one on its author's behalf.
