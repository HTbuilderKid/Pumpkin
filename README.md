## Native JavaFX health status page

This branch contains the screenshot's status cards, metric detail chart, original
daily assessment rules, persistent reading entry, and equipment guides.

- [Download the ZIP](downloads/javafx-health-status-page.zip)
- [Run and integrate the page](health-status-page/README.md)
- [Wide preview](health-status-page/docs/preview.png)
- [Narrow preview](health-status-page/docs/narrow.png)
- [Validation details](health-status-page/VALIDATION.md)

From `health-status-page`, run `mvn clean package`, then `mvn javafx:run`.
Requires JDK 21+, Maven, and a desktop display. No Python or browser is needed.
The ZIP contains a standalone demo and an embeddable Java/FXML component for
manual integration into the team's HM_repo.
