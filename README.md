## JavaFX 3D body model and markers

The drop-in component includes the original anatomical model, nine interactive
markers, rotation, zoom, severity colours, and a native JavaFX view.

- [Integration instructions](javafx-body-component/INTEGRATE.md)
- [Source and model assets](javafx-body-component/)
- [Downloadable bundle](downloads/javafx-body-drop-in.zip)
- [Compiled library JAR](javafx-body-component/lib/javafx-body-component-1.0.0.jar)
- [Rendering preview](javafx-body-component/docs/preview.png)

Requires JDK 21+, JavaFX 21+, and Gson. The x-ray shader is approximated using
JavaFX materials and outlines. See the integration guide for dependencies,
embedding examples, validation, and model attribution.
